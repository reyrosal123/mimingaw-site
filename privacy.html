Privacy Policy

Last updated: July 2026

Mimingaw is a personal automation tool operated by a single individual for personal use on their own TikTok account.

Data we access

Mimingaw uses TikTok's Content Posting API, authorized via OAuth by the account owner, solely to upload video content to that same account. It does not access followers, messages, analytics, or any data belonging to other TikTok users.

Data we store

Mimingaw stores only: (1) an OAuth access token and refresh token used to authenticate API requests, and (2) a list of previously-uploaded video identifiers, used to avoid duplicate uploads. No personal data about any third party is collected or stored.

Data sharing

No data collected or accessed by Mimingaw is sold, shared, or disclosed to any third party.

Data retention

Stored tokens and identifiers are retained only for as long as the tool remains in active use, and are deleted if the tool is decommissioned.

Contact

For questions about this policy, contact the operator directly via TikTok.
